Demographic Feature Model Report

OULAD early at-risk prediction에서 gender, region, age_band만 사용한 경우와 base feature를 추가한 경우를 비교했다.

target: target_at_risk cutoffs: week5 / week7 / week10 CV: Stratified 5-fold raw files not modified

요약

Week10 demographic only
F1 0.5025

best model: random_forest, ROC-AUC 0.5550

Week10 base + demographic
F1 0.6215

best model: logistic_regression, ROC-AUC 0.7193

Base feature lift
+0.1643

week10 ROC-AUC gain from adding active days and total clicks

결론: demographic-only는 ROC-AUC가 약 0.55 수준이라 약한 신호만 보인다. 하지만 active_days_until_cutoff, total_click_until_cutoff_mean_strategy를 추가하면 모든 cutoff에서 성능이 크게 올라간다. 즉, 학생 개인 정보는 baseline/context signal이고, 실제 예측력은 초기 LMS 활동량에서 더 크게 나온다.
